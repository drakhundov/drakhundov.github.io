# drakhundov.github.io

Personal site, served at https://drakhundov.github.io. Built by GitHub Pages with the [no-style-please](https://github.com/riggraz/no-style-please) theme.

## Writing a note

Add a Markdown file to `_notes/`, named `YYYY-MM-DD-slug.md`:

```markdown
---
title: Tiled attention, from first principles
date: 2026-11-20
---

Body in Markdown.
```

The home page shows a "notes" section, with the five most recent notes, as soon as the first note is published. The full list is at `/notes/`.

## Colours

Edit the variables at the top of `assets/css/main.scss`. The dark-mode values are in the `prefers-color-scheme: dark` block below them.
